莲渡文汇 · 莲藏 文件目录

放什么
  1. 本人整理的年表、目录、读书摘记（自己写的）。
  2. 公有领域作品，或明确允许转载的资料（请在该条目写明来源与授权方式）。
  3. 不放：他人作品的全文、扫描件、录音、付费课程、软件。

大小约定
  · 单个文件建议 ≤ 20MB。GitHub 单文件上限 100MB，超过 50MB 会收到警告，
    仓库整体也建议控制在 1GB 以内。
  · 超过 20MB 的文件，请放到外部位置（网盘或文档站），在 library/index.html
    的对应条目里写成外部链接，本站只做索引，不保证长期可用。

怎么加
  1. 把文件复制进本目录（library/files/）。
  2. 打开 library/index.html，在 AUTHORS 数组里给对应作者加一项：
     { label: '年表.pdf', href: 'files/nianbiao.pdf', note: '站内文件 · 1.2 MB' }
  3. git add / commit / push，GitHub Pages 会自动发布（约 1 分钟）。

文件名
  用英文或拼音，不要用空格，例如：luxun-nianbiao.pdf、wangli-zhuzuo.pdf
