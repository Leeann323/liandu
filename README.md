# 莲渡文汇 · Lian Du Wen Hui

一个以中文阅读与交流为主的小站：读书笔记、书目与公开资料索引、少量问答清谈，页面底部可留言。

- 站点地址：https://leeann.is-a-fullstack.dev
- 形态：**纯静态**（HTML + CSS + 一个小脚本），托管于 GitHub Pages
- 评论：Giscus（基于 GitHub Discussions，无后端、无数据库）
- 性质：**个人非商业**站点，无广告、无会员、无付费内容

## 这个仓库是什么

本站的全部源码。没有构建步骤，改完 HTML 直接提交即可生效。

## 它不是什么

- 不是论坛：不做实时版聊、用户等级、积分
- 不是资源站：**不托管、不上传、不分发**任何第三方作品；「莲藏」仅提供指向公开可访问页面的索引与简介
- 不代表任何组织，观点只代表作者本人
