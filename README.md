# 莲渡文汇 · Lian Du Wen Hui

一个以中文阅读与交流为主的小站：成篇的阅读笔记、站外文章索引、少量短评，页面底部可留言讨论。

- 站点地址：https://leeann.is-a-fullstack.dev
- 形态：**纯静态**（HTML + CSS + 几个小脚本），托管于 GitHub Pages
- 评论：Giscus（基于 GitHub Discussions，无后端、无数据库）
- 性质：**个人非商业**站点，无广告、无会员、无付费内容

## 这个仓库是什么

本站的全部源码。没有构建步骤，改完 HTML 直接提交即可生效。

## 板块

「莲叙」`/qa/` 是两个内容板块，讨论都在板块页底部，不按单篇开帖：

- **深读｜认真回答** `/qa/deep.html`：成篇笔记、版本与考据、书目比较、方法复盘
- **日常｜随手种草** `/qa/daily.html`：短句、一句话推荐、今天觉得好用的东西

每篇都带类型标签：

- **原创**：我写的 → 站内文章页，或站外（知乎、公众号、百家号）的原文链接
- **转载**：别人的好文 → 标原作者与出处，链接回原文，不搬正文
- **投稿**：读者来稿 → **全文刊在莲叙**，署名作者，不放外链

「莲藏」`/library/` 只放一样：**我自己做的东西**——写的工具、脚本、整理的资料。正文与代码放在
GitHub 仓库，站内只写一句它是干什么的。**站内不存任何文件。**

## 它不是什么

- 不是论坛：不做实时版聊、用户等级、积分
- 不是资源站：**不托管、不上传、不分发**任何第三方作品的全文；「莲藏」只放本人写的代码与整理的资料，正文在外部仓库，链接不保证长期可用
- 不代表任何组织，观点只代表作者本人
