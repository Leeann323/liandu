关 于

一个很小、很慢的中文小站

「莲渡」取两意：莲者，出于淤泥而不染，愿所收内容干净；渡者，由此岸到彼岸， 愿读的人能带着一点什么离开。「文汇」是汇合——不同来源的文字、不同人的说法，在这里并置。

它是什么

  • 形态纯静态网站 + 评论（Giscus，基于 GitHub Discussions），没有后台、没有数据库、没有账号体系
  • 更新不定期。有想写的才写，不凑数
  • 内容两个讨论板块（深读 / 日常）、文章与索引、投稿
  • 审核投稿人工读一遍再发布；留言公开发布，发现不当内容即删除
  • 成本个人自费，无广告、无会员、无付费内容

它不是什么

  • 不是论坛不做实时版聊、不做用户等级、不做积分
  • 不是资源站不托管、不分发他人作品；只做公开内容的索引与自撰笔记
  • 不是媒体不代表任何组织，所有观点只代表我自己
